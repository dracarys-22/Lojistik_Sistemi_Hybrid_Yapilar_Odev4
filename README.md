# Lojistik_Sistemi_Hybrid_Yapilar_Odev4
Kırklareli Üniversitesi Yazılım Mühendisliği Bölümü Veri Yapıları Dersi Final Ödevi kapsamında geliştirilen; Graf ve Hash Tablosu yapılarının hibrit olarak kullanıldığı Lojistik Yönetim Sistemi simülasyonudur
Lojistik Yönetim Sistemi (Graf & Hash Tablosu Hibrit Yapı)
Bu proje, bir lojistik firmasının şehirler arası bağlantılarını (Graf) ve paket bilgilerini (Hash Tablosu) yönetmek amacıyla geliştirilmiştir.
